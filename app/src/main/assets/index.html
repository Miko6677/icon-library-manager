连接测试及 API 请求会把你的 PAT 放在 Authorization 请求头发送到此主机。自定义时只使用可信的 HTTPS 代理或镜像。

应用会在基址后追加所选仓库、分支和文件路径。图片/raw 请求由 WebView 直接加载，不附带 PAT；自定义主机仍可看到请求的资源路径。

GitHub · 连接 Token

连接你的 GitHub

输入 Token 后，应用只会列出该 Token 可访问的仓库，再由你选择要管理的图标库。浏览需要读取权限；上传、删除或整理时才需要 Contents 写权限。

验证后会动态列出此 Token 可访问的仓库，并在本机加密保存。浏览只需读取权限；只有提交仓库内容变更时才需要 Contents 写权限。
